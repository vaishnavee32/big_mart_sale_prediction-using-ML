
# big_mart_sale_prediction-using-ML
- Our project "Big Mart Sale Prediction using Machine Learning" aims to develop a predictive model that estimates product sales based on historical data and product-store attributes.
- The system not only focuses on traditional sales forecasting but also introduces :
  a) Shelf Analysis to monitor product availability and placement.
  b) Multi-Objective Optimization to balance profit maximization and inventory control.
- Machine Learning algorithms : Random Forest , Decision tree Regressor. 
- Metrics used : RMSE and R^2 score
- Prediction accuracy : 64.5%
